## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们要给用户展示配置文件的变更，得精确告诉他哪一行、哪几个字被改了。请从零实现一个文本差异与补丁库，仓库现在只有一个空的 Maven 工程（只有 JUnit 5 与 AssertJ）。要求：1) 行级差异：自行实现差异算法（不允许调用现成的 diff 库），输出保留、新增、删除三种操作并保持原有行序；README 中说明你选择的算法及其时间复杂度；2) 词级差异：在行级差异基础上，对发生变化的行给出词级差异，用于展示行内改动；3) 统一格式输出：支持生成类似 unified diff 的文本，包含上下文行数与 hunk 头；4) 补丁应用：能把差异应用回原始文本，也能反向应用（撤销）；当原文与补丁的期望不匹配时必须检测并报错，不得产生错误结果；5) 三方合并：对同一份原文的两份修改做合并，冲突处输出带冲突标记的结果；6) 边界处理：空文本、全新增、全删除、超长行、中文与 emoji 等多字节字符都要有测试；7) `mvn -q verify` 跑通，测试不少于 15 个；8) README 说明算法选择、复杂度与已知限制。
